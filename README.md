# Han Mai — IBM 6500 M10 Quarto Portfolio

A separate Quarto Website project for M10: Sharing Outputs with the Audience.

## Local use

Open the RStudio project and run `quarto render`. Preview with `quarto preview --no-browser`. The website renders to `docs/`.

Main pages: Home, CEP Dashboard, CSS / SCSS, and Listings. Five summaries in `projects/` populate the native Quarto listing. The dashboard has its own dashboard format and shares `styles.scss`.

## Evidence and privacy

The CEP dashboard summarizes a dated planning snapshot and high-level project scope. It contains no client performance dataset, personal records, credentials, account identifiers, or restricted source links. Survey responses are not claimed. Coursework summaries are not client outcome evidence.


## Publication after local approval

Follow the Canvas supplemental website method: render the entire website to `docs/`, review all files, commit/push source and rendered files, then serve GitHub Pages from main /docs. Do not use a standalone report publishing command that replaces other pages.

A separate concise submission QMD/HTML with the two verified public links is prepared after publication. Canvas submission is manual.
